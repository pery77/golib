# Attribution

Files in this folder that were not made for GoLib. Keep this file with them: a
`golib dist` build ships the whole assets folder inside the executable.

## Fonts

**`fonts/FiraSans-Regular.ttf`** and **`fonts/FiraSans-Medium.ttf`**: Fira Sans Regular, the font of every text in the game, and Fira Sans Medium, for emphasis.

## Sprites

All eight PNG sheets in `sprites/` and their eight shadow masks in
`sprites/shadows/` are rendered for this game from their matching `.blend`
files in `sources/models/` using the scripts there. They need no third-party
attribution.
